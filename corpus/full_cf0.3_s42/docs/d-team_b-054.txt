Meeting Notes: Security Audit and Access Review

DATE: April 3, 2025

ATTENDEES: Selnaor Padroa, Nosos Nikeis, Finance Representative, Security Compliance Officer, IT Access Manager

DISCUSSION POINTS:

The meeting was convened to address audit findings related to access control and physical security at the Brokamis Campus, as well as to review recent changes in access protocols.

Selnaor Padroa opened the discussion by referencing audit finding XK-4148-Y and outlining the concerns raised by the external auditor. She highlighted discrepancies in the access logs for the Brokamis Campus vault, which is secured by key ID YU-1808-C. She noted that while the system logs appear consistent, the audit flagged a lack of cross-referencing between digital access and physical key tracking.

Nosos Nikeis, as the Site Reliability Lead, responded by confirming that the digital access systems for the Brokamis Campus had been updated in line with the latest security protocols. He noted that the access badge series NY-4364-K, which belongs to Selnaor Padroa, had not been flagged in internal logs for any unauthorized use. However, he acknowledged the need for a more robust cross-checking system between digital and physical access records.

The Finance Representative raised the issue of budget constraints for implementing any new access control systems. They emphasized the need to prioritize any proposed changes and ensure that all initiatives align with the broader financial planning for the next fiscal year.

The Security Compliance Officer reiterated the auditor’s concern that the current system does not fully meet regulatory expectations for physical access tracking. They recommended the introduction of a centralized access tracking log that combines data from both badge systems and physical key checkouts.

IT Access Manager proposed a phased approach to implementing the recommended changes. They suggested starting with a pilot review of the Brokamis Campus vault key tracking system and expanding to other sites if the pilot proves effective. They also raised the possibility of integrating the physical key tracking into the existing access badge portal.

DISCUSSION also touched on the potential for internal audits to be conducted more frequently and independently to detect issues earlier. There was general agreement that while external audits are valuable, they should not be the first time issues are identified.

DECISIONS:

- A pilot program will be initiated at the Brokamis Campus to integrate physical key tracking with digital access logs.
- The IT Access Manager will coordinate with the Security Compliance Officer to design the pilot framework and identify resources required.
- Selnaor Padroa will work with the finance team to draft a proposal for the pilot, referencing audit finding the same reference, and align it with the 2025–2026 financial planning cycle.
- Nosos Nikeis will lead the technical review of the Brokamis Campus access systems to identify integration opportunities for key ID noted earlier into the digital access portal.

ACTION ITEMS:

- IT Access Manager to create a task list for the pilot program by April 15, 2025.
- Finance Representative to review and provide feedback on the pilot budget proposal by April 20, 2025.
- Selnaor Padroa to submit the external audit report findings and any supporting documentation by April 18, 2025.
- Nosos Nikeis to schedule a technical review meeting with the Brokamis Campus team by April 10, 2025.

Next meeting is scheduled for April 22, 2025, to review progress and finalize the pilot proposal.
