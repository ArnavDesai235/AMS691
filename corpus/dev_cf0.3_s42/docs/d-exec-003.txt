## Platform Dependencies

Project Kridresa is built on the Barnuis Console. That relationship matters for planning because any change to the console, such as a configuration update, a permissions adjustment, or a scheduled maintenance window, can affect the project directly. Anyone proposing a change to the console should tell the project's owner in advance so that the effects can be assessed before the change goes live.

A few working expectations for the group:

- Changes to the Barnuis Console that touch shared settings should be announced to this group before they are applied.
- Questions about how Project Kridresa behaves after a console change should be raised with the project owner rather than handled informally.
- Access to the console should follow the standard approval path, and requests should be reviewed by the program owner.
